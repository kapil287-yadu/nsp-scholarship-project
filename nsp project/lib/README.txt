Place the MySQL Connector/J jar file in this folder:

Recommended:
- mysql-connector-j-8.4.0.jar (or mysql-connector-j-8.0.x.jar / mysql-connector-java-8.0.x.jar)

Where to download:
Official MySQL Community Downloads:
https://dev.mysql.com/downloads/connector/j/
(Choose "Platform Independent", download ZIP, extract the .jar file into this lib folder).

Direct Maven Central Link:
https://repo1.maven.org/maven2/com/mysql/mysql-connector-j/8.4.0/mysql-connector-j-8.4.0.jar

How to add in IntelliJ IDEA:
1. File -> Project Structure -> Libraries.
2. Click "+" (Java).
3. Select this "lib" folder or the mysql-connector-j-xxx.jar file.
4. Click Apply -> OK.
